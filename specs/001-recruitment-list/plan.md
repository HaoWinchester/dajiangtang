# 实现计划：招聘信息列表页

**分支**：`001-recruitment-list`
**规格文档**：`specs/001-recruitment-list/spec.md`
**项目宪章**：`.specify/memory/constitution.md`

## 摘要

实现招聘信息列表页，支持已登录的管理员、普通用户、企业用户查看招聘信息。列表展示岗位、薪资、
公司名称、城市、负责人、需求人数，支持岗位模糊搜索、标准城市名搜索、默认每页 10 条翻页。
管理员可见新增按钮，普通用户和企业用户不可见。默认仅展示正在招聘或有效岗位，并按最新发布或
最近更新优先排序。

## 技术上下文

- 运行环境：浏览器端单页应用 + Java 后端服务。
- 开发语言：前端 TypeScript 或 JavaScript；后端 Java。
- 技术框架：前端 Vue；后端 Java REST 服务，推荐 Spring Boot 风格组织。
- 数据层：关系型数据模型，招聘信息表支持状态、城市、岗位、发布时间、更新时间索引。
- 认证与角色：沿用登录态中的用户角色，至少支持管理员、普通用户、企业用户。
- 外部依赖：无强制外部服务；城市标准名可先使用系统内置城市字典或后端枚举。
- 约束条件：新增招聘表单不在本功能范围；未登录访客不访问本列表页；CSPM 优先不在本列表页展示。
